청년 취업 정보 추천 플랫폼

채용정보와 청년 지원정책을 한 곳에서 확인하세요.

프로젝트 소개

청년들이 취업을 준비하면서 여러 사이트에 흩어진 채용정보와 취업 지원정책을 각각 찾아야 하는 불편함을 해결하기 위한 플랫폼입니다.

주요 기능

  • 채용정보 조회
  • 청년 취업 지원정책 조회
  • 사용자에게 필요한 취업정보 제공

API 활용

다양한 채용정보를 제공하기 위해 채용정보 API를 활용하여 구직자에게 필요한 채용공고를 제공할 예정입니다.
